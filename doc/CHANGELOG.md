# 更新日志

记录 AstrBot 桥接层（本插件）的用户可见变更。版本号与上游
nonebot-plugin-parser-lite 对齐，桥内修复不独立 bump；上游解析能力的变更
随 vendor 快照滚动同步，见上游仓库 releases。

## 2026-10-12

- 修复：视频/语音/文件在协议端上传失败后静默丢失。此类单组件媒体链现由插件直发，
  并按 15、45 秒退避重试（最坏多等 60 秒）；重试耗尽时表情回应记为失败而非完成。
- 取舍（有意为之，非隐藏变更）：换取上述重试能力的代价是这三类媒体链不再经过宿主发送
  流程——不触发 `filter.on_decorating_result()`（发送消息前）与 `filter.after_message_sent()`
  （发送消息后）钩子，不做 `platform_settings.path_mapping` 路径映射（只影响文件消息），
  也不受分段回复节奏约束。文本、图片与合并转发链不受影响；依赖这些钩子改写媒体、或依赖
  路径映射投递文件的插件需知悉。

## 2026-10-11

- 修复：上游平台接口返回 4xx/5xx 时按解析失败收尾——日志记一行端点摘要（路径
  截断），不再落 ERROR 完整堆栈；开启「解析失败时向会话发送简短错误说明」后
  会话里回的是状态码，端点不外显。
- 修复：文转图服务返回非图片字节（错误页 / 空响应）时在产出点即失败并在日志
  带产物字节头，故障可定位；卡面降级文本的行为不变。

## 2026-09-13

- 修复：解析完成后多出的一条空消息记录（未实际发送）与多余的发送后钩子
  触发。
- 修复：渲染卡片长图缓存命中复用，落盘转 jpeg（同链接短时间内重复解析
  不再重新渲染，缓存体积约为原来的 1/8）。
- 修复：超过 5MB 的渲染卡片长图按文件消息发送；私聊不再尝试表情回应
  （私聊不支持，此前每次解析告警）。
- 修复：kuwo/buff/hupu 平台的运行态解析缺陷经桥内注入补丁修正。
- 安全：ffmpeg HLS 子进程出站纳入 SSRF 校验；SSRF 第 4 层重写为连接级
  钉扎。

## 2026-09-12

- 初版发布：B 站/抖音/小红书等平台分享链接自动解析并转发媒体内容
  （上游 standalone 快照 vendored + 两层注入桥接）。
- 修复：插件卸载时 curl_cffi 清理非幂等导致的告警。
- 安全：出站请求经 SSRF 防线校验（scheme 白名单 / 端口规则 / 逐 IP 检查 /
  解析即连接钉扎）。
